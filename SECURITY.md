# Security policy

Stannum reads power system case files on your machine and does not send them
anywhere. If you find a way to make it run code, read or write files it
shouldn't, or leak case data, please report it privately.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's
[Security tab](https://github.com/SklorGalore/StannumRevival/security/advisories/new).
Please don't open a public issue for it.

Include the version or commit, the steps or a case file that shows the
problem, and what you expected to happen. You should hear back within a week.

## Supported versions

Fixes go into `main` and the next release. Older releases get a fix on a
`release/x.y` branch only when the problem is serious.
