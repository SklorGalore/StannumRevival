---
title: Keyboard shortcuts
description: Every keyboard shortcut in Stannum.
---

On macOS, use <kbd>Cmd</kbd> where this page says <kbd>Ctrl</kbd>.

## Anywhere

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the [palette](/StannumRevival/guide/command-palette/): find an element or run a command |
| <kbd>Ctrl</kbd>+<kbd>`</kbd> | Open or close the [log](/StannumRevival/guide/log/) |
| <kbd>Esc</kbd> | Clear the selection |
| <kbd>←</kbd> / <kbd>→</kbd> on the divider | Resize [side by side](/StannumRevival/guide/side-by-side/) panes |

## In the palette

| Keys | Does |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move through results |
| <kbd>Enter</kbd> | Show the element in every module, or run the command |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Draw a one-line around the element |
| <kbd>Esc</kbd> | Close |

## In the diagram

These act only while the diagram is showing.

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy, cut, paste |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the diagram |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| <kbd>Esc</kbd> | Clear the selection |
| Arrow keys | Nudge one grid step (<kbd>Shift</kbd> for 1 px) |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd> | Rotate clockwise / back; on a bus, horizontal ⇄ vertical |
| Space + drag, middle or right drag | Pan |
| Drag on empty canvas | Box select (<kbd>Shift</kbd>/<kbd>Ctrl</kbd>-click adds) |
