---
title: Keyboard shortcuts
description: Every keyboard shortcut in Stannum.
---

On macOS, use <kbd>Cmd</kbd> where this page says <kbd>Ctrl</kbd>. Press
<kbd>?</kbd> anywhere outside a text field to see this list in the app.

## Anywhere

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the [palette](/StannumRevival/guide/command-palette/): find an element or run a command |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> to <kbd>4</kbd> | Show Diagram, Power flow, Records or Case diff |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> to <kbd>4</kbd> | Open that module [side by side](/StannumRevival/guide/side-by-side/) |
| <kbd>Ctrl</kbd>+<kbd>`</kbd> | Open or close the [log](/StannumRevival/guide/log/) |
| <kbd>Esc</kbd> | Clear the selection, or close a menu or dialog |
| <kbd>?</kbd> | List the keyboard shortcuts |
| <kbd>←</kbd> / <kbd>→</kbd> on the divider | Resize [side by side](/StannumRevival/guide/side-by-side/) panes |
| <kbd>Tab</kbd> first thing in the window | **Skip to the module**, past the rail, the menu bar and the toolbar |

## Tables, tabs and menus

Every table is one <kbd>Tab</kbd> stop, and so is every row of tabs.

| Keys | Does |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>PgUp</kbd> / <kbd>PgDn</kbd>, <kbd>Home</kbd> / <kbd>End</kbd> | Move between a table's rows |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Open the row, as a click does |
| <kbd>↑</kbd> on the first row | Go to the column headers: <kbd>←</kbd> / <kbd>→</kbd> choose, <kbd>Enter</kbd> sorts, <kbd>↓</kbd> goes back |
| <kbd>F2</kbd> in Records | Edit the row's first editable field; <kbd>Tab</kbd> moves to the next, <kbd>Enter</kbd> keeps, <kbd>Esc</kbd> cancels |
| <kbd>←</kbd> / <kbd>→</kbd> on a tab | Switch tabs |
| <kbd>↓</kbd> on a menu button | Open the menu; <kbd>↑</kbd> / <kbd>↓</kbd> move, <kbd>Enter</kbd> chooses, <kbd>Esc</kbd> closes |

## In the palette

| Keys | Does |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move through results |
| <kbd>Enter</kbd> | Show the element in every module, or run the command |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Draw a one-line around the element |
| <kbd>Esc</kbd> | Close |

## In the diagram

These act only while the diagram is showing.

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy, cut, paste |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the diagram |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| <kbd>Esc</kbd> | Clear the selection |
| Arrow keys | Nudge one grid step (<kbd>Shift</kbd> for 1 px) |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd> | Rotate clockwise / back; on a bus, horizontal ⇄ vertical |
| Menu key or <kbd>Shift</kbd>+<kbd>F10</kbd> | Case actions for the selected symbol (bring in neighbours, draw around) |
| Space + drag, middle or right drag | Pan |
| Drag on empty canvas | Box select (<kbd>Shift</kbd>/<kbd>Ctrl</kbd>-click adds) |
